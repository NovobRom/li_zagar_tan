## Резюме

Сайт в хорошей форме: современный стек (Next.js 16, React 19, Tailwind 4, Supabase), три языка, аккуратный дизайн, работающая админка с галереей, продуманная базовая SEO-разметка. Это сильный фундамент.

Главные проблемы — не «сломанное», а **недоделанное**: маркетинговые скрипты подключены с нарушением GDPR, часть SEO-механики фиктивна (hreflang ведёт в никуда, schema ссылается на несуществующую картинку), а самый ценный контент — фото «до/после» — невидим для поисковиков, потому что грузится только в браузере.

**Топ-5 по влиянию на бизнес:**

1. 🔴 Meta Pixel и Vercel Insights грузятся **без согласия на cookie** — штрафной риск GDPR для бизнеса в ЕС
2. 🔴 Галерея результатов **отсутствует в HTML для поисковиков** — Google не видит главное доказательство качества работы
3. 🔴 JSON-LD разметка ссылается на **несуществующую картинку** и чужой домен — портит право на rich-результаты в Google
4. 🟠 hreflang-ссылки указывают на URL, которые **не переключают язык** — русско- и англоязычные клиенты ищут и не находят
5. 🟠 `/admin/audit-logs` не защищён на уровне маршрута; нет middleware; rate-limiter при сбое БД **пропускает всех**

## 1. GDPR и аналитика

| # | Серьёзность | Находка | Где |
|---|---|---|---|
| 1.1 | 🔴 | **Meta Pixel грузится без согласия.** Скрипт вставляется всем посетителям, если задан `NEXT_PUBLIC_FB_PIXEL_ID`; баннер cookie на него не влияет. Для салона в Литве (ЕС) это прямое нарушение ePrivacy/GDPR | `app/layout.tsx:125-141` |
| 1.2 | 🟠 | **Vercel Insights грузится безусловно.** Он cookieless, но решение «гейтить или задокументировать» должно быть осознанным и отражено в политике конфиденциальности | `app/layout.tsx` |
| 1.3 | 🟠 | **GA ID захардкожен** (`G-23N94VFY9M`), переменная `NEXT_PUBLIC_GA_ID` из `.env.example` не читается вовсе | `app/components/GoogleAnalyticsWrapper.tsx:6` |
| 1.4 | 🟡 | **Опрос localStorage каждую секунду** для отслеживания согласия — лишний таймер на всё время жизни страницы; правильное решение — события | `GoogleAnalyticsWrapper.tsx:25` |

**Влияние на бизнес:** штрафы за GDPR в Литве реальны даже для малого бизнеса (надзорный орган VDAI активен); плюс политика конфиденциальности сайта сейчас упоминает только Google Analytics, что делает её неточной.
**Исправление:** `openspec/changes/fix-analytics-consent/` (8 задач).

## 2. SEO

| # | Серьёзность | Находка | Где |
|---|---|---|---|
| 2.1 | 🔴 | **Галерея и фото «Обо мне» грузятся client-side** (`useEffect`) — их нет в серверном HTML. Поисковики и превью соцсетей не видят фото результатов — ключевой контент для салона | `GallerySection.tsx:22-43`, `AboutSection.tsx:15-21` |
| 2.2 | 🔴 | **JSON-LD `image` указывает на несуществующий `/og-image.jpg`** (в `public/` есть только `opengraph-image.png`). Google может из-за этого не показывать rich-результат со звёздами | `StructuredData.tsx:12` |
| 2.3 | 🔴 | **Два разных fallback-домена:** `StructuredData` использует `li-zagar-tan.vercel.app`, остальной код — `www.lizagartan.com`. Если env-переменная не задана, разметка укажет на чужой домен | `StructuredData.tsx:5` vs `layout.tsx` |
| 2.4 | 🟠 | **hreflang ведёт на `/?lang=lt\|ru\|en`, но параметр `?lang` нигде не обрабатывается** — все три «версии» отдают литовский. Фиктивный hreflang хуже его отсутствия | `app/layout.tsx:90-94` |
| 2.5 | 🟠 | **Sitemap содержит только главную**, `/privacy` отсутствует (в коде даже есть комментарий, что надо добавить) | `app/sitemap.ts` |
| 2.6 | 🟠 | **SEO-keywords заданы только для литовского**; блоки `ru` и `en` их не имеют — а это языки, на которых ищет заметная часть клиентов | `app/layout.tsx:27` vs `42-75` |
| 2.7 | 🟡 | **Alt-тексты фото генерические** (`Spray tan result {id}`), хотя в БД есть колонки `alt_text_lt/ru/en` — они просто не используются. Потерянный трафик из Google Images | `GallerySection.tsx:72` |
| 2.8 | 🟡 | Первому посетителю (и краулеру) метаданные всегда отдаются на литовском (cookie ещё нет) — следствие client-side i18n, лечится per-language URL-ами | `app/layout.tsx` |

**Влияние на бизнес:** локальный салон живёт за счёт поиска «purškiamas įdegis Vilnius» / «моментальный загар Вильнюс». Пункты 2.1–2.4 — это буквально невидимость части контента и языков.
**Исправления:** `fix-seo-structured-data/` (7 задач), `fix-hreflang-language-urls/` (5 задач), `ssr-gallery-and-about/` (6 задач).

## 3. Безопасность админки

| # | Серьёзность | Находка | Где |
|---|---|---|---|
| 3.1 | 🟠 | **`/admin/audit-logs` не защищён guard-ом страницы/лейаута** — защита только внутри server action. Работает, но одна забытая проверка в новой странице = открытая дверь | `app/admin/audit-logs/page.tsx` |
| 3.2 | 🟠 | **Нет `middleware.ts`** — Supabase-сессии не обновляются централизованно; в `supabase-server.ts` даже остался комментарий, рассчитывающий на middleware | корень репо, `app/lib/supabase-server.ts` |
| 3.3 | 🟠 | **Rate-limiter «fails open»:** при ошибке запроса к БД возвращает `true` (разрешить). Считает при этом все действия скопом, а не по типу | `app/lib/security.ts:66-71` |
| 3.4 | 🟡 | Google-verification токен и GA ID закоммичены в код (не секреты, но лучше в env) | `app/layout.tsx:97` |

**Что сделано хорошо:** каждое мутирующее действие проверяет `is_admin` RPC + auth; magic-bytes валидация загрузок; `deletePhoto` сверяет `storage_path`; audit-лог всех действий; в репозитории нет service-role ключей.
**Исправление:** `harden-admin/` (7 задач).

1. **Результат за 30 минут** - быстро, удобно
2. **Безопасно** - без UV, без вреда для кожи
3. **Натуральный вид** - никто не догадается
4. **7-10 дней** - долгий эффект
5. **4.9★ рейтинг** - социальное доказательство
6. **Профессиональные продукты** - качество

### Целевая аудитория:
- Женщины 25-45 лет
- Готовящиеся к событиям (свадьба, отпуск, фотосессия)

## 4. АРХИТЕКТУРА ДЛЯ ПОДДЕРЖАНИЯ

### Текущая структура:
```
app/
├── components/          # UI компоненты
├── context/             # React контексты (язык)
├── i18n/                # Переводы
│   └── translations/

└── layout.tsx           # Основной layout
```

### Рекомендуемая структура (масштабируемая):
```
app/
├── (marketing)/         # Лендинг страницы
│   ├── page.tsx         # Главная
│   ├── course/          # Страница курса
│   └── about/           # О мастере
├── (admin)/             # Админ-панель (защищённая)
│   ├── dashboard/
│   ├── gallery/         # Управление галереей
│   └── reviews/         # Управление отзывами
├── api/                 # API routes
│   ├── gallery/
│   ├── reviews/
│   └── contact/
├── components/
│   ├── ui/              # Базовые UI компоненты
│   ├── sections/        # Секции лендинга
│   └── forms/           # Формы
```
